# Recorded link surface of libtoffy_oatpp — the toffy symbols this library binds to.
#
# One demangled symbol per line, as `nm -D --undefined-only` reports them after
# c++filt. DO NOT HAND-EDIT; regenerate with
#   nm -D --undefined-only <libtoffy_oatpp.so> | awk '$1=="U"{print $2}' \
#     | c++filt | grep -E 'toffy::' | sed 's/std::__cxx11::/std::/g' | sort -u
# and read the diff before committing it.
#
# The direction that matters is *additions*: this library exists to be the thin
# HTTP/JSON edge against libtoffy, and every new toffy symbol it reaches across is
# coupling nobody agreed to. Removals are progress and are reported, not failed.
#
# Blessed from a **BTA-off** build, because that is what a hosted runner builds and
# what the CI cell checks. A BTA-on build adds `toffy::capturers::Bta::*` and
# `toffy::bta::init` — 16 symbols rather than 15 — and shows them as additions,
# which is allowed. The same rule toffy applies to its own ABI baseline, learned the
# hard way there: bless the configuration the gate actually runs.
#
# Cross-check: toffy records the same surface in its own ci/consumer-link-surface.txt
# (15 BTA-off / 16 BTA-on). If the two disagree, one of them has drifted.
